# 📚 Library Wallet Tracker

A simple and beautiful web app to **track your monthly wallet** in a library or academic setting.  
It shows your **current month's balance**, allows you to **update your wallet**, and generates a **50/30/20 budget split** with a **live pie chart** using Chart.js.

---

### 🌐 Live Features

- 📅 Displays current month only
- 💸 Update or add money to your wallet
- 📊 Automatically calculates:
  - ✅ **50% for Needs**
  - 🎉 **30% for Wants**
  - 💰 **20% for Savings**
- 📈 Interactive **pie chart** showing budget breakdown
- 🔐 Stores monthly data securely in your browser (localStorage)

---

### 🧠 Budget Rule: 50/30/20

| Category | Percentage | Description                  |
|----------|------------|------------------------------|
| Needs    | 50%        | Rent, bills, food, etc.      |
| Wants    | 30%        | Entertainment, hobbies       |
| Savings  | 20%        | Investments, savings account |

---
